::: table {"widths": [0.31, 0.69], "headers": true}
| Symptom | Try this |
| --- | --- |
| Still seeing the demo | Finish official approval; check connection status and wait for Loading library. |
| Library looks old | Reload; if needed, Download everything again in the connection dialog. Preserve drafts first. |
| Saving seems slow | Wait for read-back; large libraries take time. Do not repeat a write. |
| Album fields blocked | Disable Combine Multi-Disc Album Sets in iBroadcast; reload. Supported track edits may already have succeeded. |
| No lyrics / wrong timing | Check source mode, LRCLIB and the open Lyrics view. Retry offered temporary failures; the exact version may be absent. |
| Gap or buffering | Compare normal playback/Original; check service/network health. Unsupported Gapless boundaries use ordinary playback. |
| Missing local preferences/history | Check account, profile, settings folder and port. Saved iBroadcast metadata is separate. |
| Upload stopped / needs checking | Inspect iBroadcast before preparing again. Stop may wait for a read; accepted files may still arrive. |
| Old interface after updating | Quit the old app; reopen the intended complete package and check its version before resetting data. |
| First setup did not appear | Existing installations are not new. Open Settings > Interface > First setup. |
| Details shows another album | It follows the current queued track, not the browsed album. |
| Reference tracks do not align | Check the edition/pairing; leave uncertain corrections unselected. |
| No in-app installer | Check the platform route. Install 1.9.0 manually from older versions. |
| Install postponed | Finish checks; inspect uncertain results. Ordinary Quit never installs. |
:::

::: small
For a bug report, include version, operating system, desktop/browser mode and exact steps/message. Remove private account details, paths and tokens from screenshots/logs. Use [GitHub Issues](https://github.com/cyberdeliaAI/tagcast/issues) for reproducible problems or [r/Tagcast](https://www.reddit.com/r/Tagcast/) for discussion.
:::
