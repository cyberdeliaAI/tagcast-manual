## Overview

Overview shows collection totals, formats, playing time, account information and existing iBroadcast settings. **Metadata health** links to missing metadata/artwork and **Clean up metadata**. Opening Overview does not start cleanup or change your library.

The album totals can differ: Overview uses iBroadcast's native totals; sidebar and browser cards count Tagcast's displayed disc groups. Separate discs may count individually in iBroadcast.

## Public service health

**iBroadcast Service Status** covers Streaming, API Server, Play Queue, Artwork and Library Generation. Readable states accompany the indicators: **Operational**, **Degraded performance**, **Service disruption** and **Unknown / unavailable**. Open the details for any issue text.

The panel checks about every five minutes while Overview is visible. Last successful retrieval, provider report time and stale/unavailable notices help you judge freshness. Stale information is not presented as confirmed current Operational status. A failed status-feed request does not prove iBroadcast is down.

::: callout
Global status is not your account connection

An operational API can coexist with a disconnected Tagcast session. A global streaming report cannot establish whether one particular track will play. The official status-page link shows iBroadcast's own report.
:::

## Optional discovery

Enable **1001 Albums** in Settings > Discovery, then explicitly choose **Analyse my library**. It compares your loaded metadata with a bundled reference; it does not buy or download music. Review uncertain matches manually.

Artist biographies and album background information are separate opt-in TheAudioDB features for visited pages. Available bundled album text takes priority. Source attribution remains visible. Some text is available only in English.
