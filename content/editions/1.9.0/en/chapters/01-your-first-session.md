Tagcast is a local metadata editor and music player for your own iBroadcast library. Use it to browse, listen, organise and correct metadata. It runs as a desktop app, or as a local Python server with the same interface in a browser.

**1.**  Install the package for your computer, install or extract it completely and open Tagcast. The sample library is a preview; it is normal to see it before signing in.

**2.**  Choose **Connect iBroadcast**. Approve access on the official iBroadcast website, then leave Tagcast open while it loads your library.

**3.**  Complete **First setup** if offered, or choose Set up later. Then open **Album artists** or **Albums**. Search, open an album and choose **Play** to listen.

**4.**  For your first edit, choose **Edit**, change one field, open **Review draft** and inspect the before/after values. Only the final Save sends metadata.

**5.**  Wait for confirmation. **Checking** means verification is still running; a large library can take time. Continue browsing or listening while ordinary checks finish.

::: callout
Before album edits

In iBroadcast, turn **Combine Multi-Disc Album Sets** off, then reload Tagcast. Tagcast groups compatible discs itself and needs their original records to save album changes.
:::

Your original music files are not retagged. Explicit downloads create separate copies; explicit uploads read the existing embedded tags in your chosen files. Neither happens merely by browsing.
